# Сон — APK для Android

Как получить APK без Android Studio:
1. Создайте репозиторий на github.com и загрузите в него всё содержимое этой папки (включая скрытую папку .github).
2. Откройте вкладку Actions, дождитесь зелёной галочки у Build APK (около 5 минут).
3. Откройте завершённый запуск, внизу в Artifacts скачайте sleep-apk, внутри лежит app-debug.apk.
4. Разрешите установку из неизвестных источников и установите APK.

Данные хранятся во внутреннем хранилище приложения и остаются после перезапуска и обновления.
При удалении приложения они пропадут, поэтому иногда жмите «Скопировать копию».
